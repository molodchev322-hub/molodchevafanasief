# Статус файлов artifacts

Файлы JSON в этой папке — снимок до исправления извлечения E-17 и до согласования конфигурации модели. Метаданные старого `eval_*.json` содержат `qwen3-4b-local:latest`, тогда как рекомендуемая конфигурация проекта в `.env.example` — `qwen3:4b-instruct-2507-q4_K_M`.

Поэтому текущие `graph.json`, `communities.json`, `index_stats.json` и `eval_*.json` сохранены для диагностики, но не должны использоваться как финальные результаты новой версии. После распаковки архива, настройки Ollama и запуска `make index`, `make eval-all`, `make eval-extraction` перезапишите их согласованными результатами. Перед новым прогоном удалите старый кеш `artifacts/llm_cache/`, если он есть.
